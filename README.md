# mpliment — Music Website

정적 HTML/CSS/JavaScript로 제작된 음악 플레이리스트 및 아티스트 소개 홈페이지입니다. 빌드 과정이나 별도 서버가 필요하지 않습니다.

## GitHub Pages 무료 게시
1. GitHub에 로그인 후 **New repository**를 누르세요. 예: `mpliment-site` (Public).
2. 이 압축파일을 해제하고 `index.html`, `style.css`, `script.js`, `favicon.svg`를 저장소 최상단에 업로드(Upload files)하세요.
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로 선택하세요.
4. Branch를 **main**, 폴더를 **/(root)**로 지정한 다음 Save를 누르세요.
5. 배포가 완료되면 `https://사용자아이디.github.io/mpliment-site/`로 접속할 수 있습니다.

## 맞춤 설정
- `index.html`에서 플레이리스트 이름, 아티스트 소개, YouTube 링크 수정 가능
- 현재 유튜브 카드들은 **직접 영상 링크가 아닌 검색 링크**입니다. 실제 영상 URL로 교체하면 바로 해당 영상으로 이동합니다.
- `style.css`에서 색상, 타이포그래피, 반응형 레이아웃 수정 가능
- 음악 파일이나 동영상 원본을 서버에 업로드하지 않고 유튜브로 연결하는 방식입니다.
- 폰트는 Google Fonts를 사용하므로 네트워크가 안 되면 시스템 폰트로 대체됩니다.

## 참고
GitHub Pages는 정적 웹사이트를 지원합니다. GitHub 무료 플랜에서는 공개 저장소 기준으로 GitHub Pages를 이용할 수 있으며, 이용량과 정책 제한이 적용됩니다.
